# Security Policy

## Supported versions

Only the latest development branch is currently supported.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting for this repository when available. Include affected commit or version, reproduction steps, impact, and any suggested mitigation.

Do not include real credentials, personal financial information, or production customer data in reports.

## Security scope

The current repository is a foundation. It is not a broker, exchange, custody service, or trading execution system. Do not submit live credentials or API secrets as test data.
